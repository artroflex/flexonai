# 블로그 콘텐츠 자동화

## 설치는 더블클릭 한 번 — 패키지 설치마법사

- 윈도우: 이 폴더의 **`패키지설치마법사.cmd`** 를 더블클릭
- 맥: 이 폴더의 **`패키지설치마법사.command`** 를 더블클릭(처음 한 번 막히면 마우스 오른쪽 클릭 → [열기])

마법사가 묻는 값만 넣으면 DB 만들기·설정·빌드·인터넷에 올리기까지 끝납니다. 필요한 화면은 마법사가 브라우저로 열어 줍니다.
자세한 설명과 그다음 단계는 [`KIT/README.md`](KIT/README.md), 플랫폼별 가입·API 키 발급은 [`KIT/PLATFORMS.md`](KIT/PLATFORMS.md)에 있습니다.
